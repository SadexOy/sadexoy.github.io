SafeLine cable system

Working on a roof always involves risks, but they can be managed when roof fall protection has been designed and implemented correctly. SafeLine offers a comprehensive solution for safety rope and safety harness anchor points, which are an essential part of roof safety in both new construction and renovation.

A safety rope anchor point ensures that roof maintenance workers can move about the roof safely. In many properties, especially housing companies and industrial halls, fall protection is easily overlooked. In reality, it is an essential part of the overall roof safety product package, protecting both the workers and the building owner. The safety of the roof in use is always the property owner’s responsibility.

Safeline is designed especially for demanding conditions in which moving about on the roof requires a reliable safety rope attachment.

Get roof fall protection in order with SafeLine

The Pisko SafeLine cable system takes safety when moving about on the roof to a new level. The continuous access route from the ground onto the roof and across it, long awaited on the market, is finally available. The SafeLine cable system is an extremely safe anchor point for safety ropes and safety harnesses, because it gives the user both the continuous access route required by the building regulations and fall protection from ground level to the maintenance point and back.

The user is attached to the cable system at all times in case of a fall, and there is no longer any need to change anchor points. The system is conveniently fixed to Pisko access routes such as wall ladders, roof ladders and roof walkways, so no extra parts need to be installed for the anchor points. This is the recommended and cost-effective solution, but the system can also be fixed directly to the structure separately.

Made from stainless steel, the modular Pisko SafeLine cable system is versatile – it can be a single continuous length or assembled from fixed-length parts. The system also allows several people to be attached at the same time.

The Pisko SafeLine cable system is quick and easy to install. The hinged part of the bracket locks the cable in place, so the system does not need to be tensioned separately; it can be installed in one go at the right tension. Installation can also be done with ordinary installation tools, without special tools.

The cable system’s sliding anchor works in all weather conditions

The cable system’s sliding anchor travels very smoothly along the cable with the user and never needs to be detached at any point. Made from acid-resistant steel, the sliding anchor works flawlessly in winter conditions too.

The sliding anchor is certified as part of the Pisko SafeLine system. It has also been tested as a separate item of personal protective equipment, and the sliding anchor carries CE marking in accordance with EN 795.

  • An anchor point that moves with the user ensures that the user stays safely connected along the entire access route
  • Allows several users to be attached at the same time
  • Easy to install directly on Pisko access routes without special tools
  • Works in all weathers
  • Easily customised for a wide range of sites
  • In a fall, protects the user thanks to the give in the cable
  • Cost savings for projects: replaces two separate solutions for providing a continuous access route and fall protection
  • Makes it easier to draw up a property-specific safety plan and the property’s user instructions
  • Long-lasting (50-year technical warranty) with little need for special maintenance
